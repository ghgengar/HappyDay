# Поздравлятор
Приложение для ведения списка дней рождения друзей, коллег, знакомых


## Возможности
- Просмотр **всего списка** дней рождения с возможностью сортировки.
- Разделение записей на **текущие** (сегодня и будущие) и **прошедшие**.
- Отображение **сегодняшних** и **ближайших** ДР (первые 3 будущих).
- **Добавление**, **удаление**, **редактирование** записей.
- **сохранение** в текстовый файл при выходе.

> Программа написана на Python и работает в консоли.


## Установка и запуск

1. **Клонируйте репозиторий** (или скачайте файл `HappyDay.py`):
   ```bash
   git clone https://github.com/ghgengar/HappyDay.git
   cd HappyDay
2. Убедитесь, что установлен **Python 3.6+**
3. Запустите программу
   ```bash
   python HappyDay.py
Если файл базы данных (HappyDayBase.txt) не существует, он будет создан автоматически

## Использование
После запуска появится главное меню:

[Главное]  
1 - Список ДР  
2 - Сегодняшние и ближайщие ДР  
3 - Добавление записей ДР  
4 - Удаление записей ДР  
5 - Редактирование записей ДР  
0 - Сохранить и выйти

Пункт 1 - показывает весь список. Далее доступны дополнительные опции: сортировка, разделение на текущие/прошедшие.  
Пункт 2 - сразу выводит именинников сегодня и первые 3 будущих.  
Пункты 3-5 - позволяют управлять записями.  
Пункт 0 - сохраняет данные в файл и завершает работу.


## Пример добавления записи
Имя (например, Иван): Иван  
Фамилия (например, Иванов): Петров  
День рождения (например, 1 апреля): 15 мая  
Добавить запись Иван Петров: 15 мая? y/n: y  
Запись успешно добавлена!


## Формат файла данных
Все записи хранятся в файле HappyDayBase.txt (обычный текст) в кодировке UTF-8.  
Каждая строка соответствует одной записи и имеет вид:  
Имя Фамилия: день месяц  

Пример:  
Иван Петров: 15 мая  
Анна Сидорова: 23 декабря  

Программа сама создаёт и читает этот файл. Вручную редактировать его можно, но соблюдайте формат.
